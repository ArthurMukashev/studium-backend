# Проект "NestJS Boilerplate"

# Инструкция

## Структура приложения

```
|__prisma/                - PrismaORM
|____dbml/                - DBML (автогенерируемая диаграмма dbdiagram.io)
|____models/              - Multi-file модели Prisma (PrismaSchemaFolder)
|____seeds/               - Сидеры
|__schematics/            - Схематика (генератор ресурсов)
|__src/                   - Ядро приложения
|____common/              - Вспомогательные модули (JwtAuth, MyLogger, Prisma)
|____constants/           - Константы, используемые внутри проекта
|____decorators/          - Декораторы
|______context/           - Декораторы, работающие с контекстом исполнения (Execution Context)
|______dto/               - Декораторы, применяемые к полям в DTO
|______meta/              - Декораторы, устанавливающие метаданные
|______query/             - Декораторы, применяемые к сигнатуре методов контроллера (доп. параметры)
|____guards/              - Гуарды (защитники маршрутов, модулей)
|____interceptors/        - Перехватчики ответов на запросы
|____lib/                 - Библиотеки
|______cookie/            - Библиотека работы с Cookie
|______utils/             - Вспомогательные утилиты
|____middlewares/         - Мидлвары
|____modules/             - Модули
|______admin/             - Административный слой
|______app/               - Слой приложения
|______client/            - Клиентский слой
|______service/           - Сервисный слой
|____types/               - Типы
|______dto/               - Типы, применяемые в DTO (от них можно наследоваться)
|__test/                  - Тесты
```

## Как создать ресурс

```shell
yarn generate:resource
```

- Скрипт спросит название ресурса и попросит выбрать расположение (слой)
- Скрипт автоматически создаст пачку модуль, контроллер, сервис, репозиторий, каталог с DTO и пакетные файлы (index.ts)
- Скрипт автоматически зарегистрирует модуль в соответствующем слое (роутер-модуле)
- После этого выполнится команда ```shell
yarn format``` для форматирования всех файлов

# Деплой

## .env

- Обязательно:
    - DATABASE_URL
- Опционально:
    - PORT

## Docker

- ```shell
    docker-compose up -d // поднимает БД и редис
    ```
- ```shell
    npx prisma migrate deploy // Запускает миграции и генерирует тестовые данные
    ```
